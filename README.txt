VERSION 5 — EDITABLE EVENT CALENDAR

The website now includes:
- Monthly event calendar
- Upcoming-events list
- Event posters
- Vietnamese and English event content
- A simple offline event editor

HOW TO ADD AN EVENT
1. Open event-editor.html in Chrome or Edge.
2. Enter the event details.
3. Upload the event poster.
4. Click Save event.
5. Click Download events-data.js.
6. Replace the old events-data.js in the website folder with the downloaded file.
7. Upload the complete website folder to Netlify again.

The uploaded poster is embedded inside events-data.js, so you do not need to copy a separate poster file.
For faster loading, keep each poster below approximately 1–2 MB.


VERSION 6 — EDITABLE MENU

HOW TO EDIT THE MENU
1. Open menu-editor.html in Chrome or Edge.
2. Add or edit the item name, category, price and descriptions.
3. Upload an item image.
4. Click Save item.
5. Click Download menu-data.js.
6. Replace the existing menu-data.js in the website folder.
7. Upload the complete website folder to Netlify again.

Uploaded images are embedded into menu-data.js. Keep each image below 1–2 MB.


VERSION 7 — EDITABLE GALLERY

The website now includes:
- Dynamic gallery loaded from gallery-data.js
- Full-screen image viewer with previous/next controls
- Bilingual captions
- Lazy-loaded images
- gallery-editor.html for adding, editing, reordering, and deleting images

HOW TO EDIT THE GALLERY
1. Open gallery-editor.html in Chrome or Edge.
2. Add one or several images.
3. Add captions and choose Normal, Tall, or Wide layout.
4. Use Edit, Delete, Up, or Down to manage the gallery.
5. Click Download gallery-data.js.
6. Replace the existing gallery-data.js in the website folder.
7. Upload the complete website folder to Netlify again.

Keep images below approximately 1–1.5 MB each for good loading speed.
